# 上級の数学機能とシンプルモード

## 表示モード

| モード | 表示する内容 | 想定する利用者 |
| --- | --- | --- |
| シンプル（初期値） | 基本的な単位、四則演算、通常のサンプル | 日常・業務の単位換算を素早く行う利用者 |
| 上級 | 角度、加速度、周波数、科学・航海系の特殊単位、上級サンプル、数学キー | 理工学・測量・振動・教育用途の利用者 |

モードは **設定 → 電卓の表示モード** で切り替え、端末内に保存されます。シンプルモードでも、保存済み履歴の表示や基本単位の計算精度は変わりません。

## 上級の数学構文

| 構文 | 例 | 結果・ルール |
| --- | --- | --- |
| 三角関数 | `sin(30deg)` | `0.5`。引数は `rad`、`deg`、`°`、または無次元値のみです。 |
| べき乗 | `(2m)^3` | `8 m³`。単位付き値の指数は整数に限定します。 |
| 平方根 | `sqrt(144cm²)` | `12 cm`。単位付き値は各次元の指数が偶数である必要があります。 |
| 円周率 | `sin(π / 2)` | `1`。`π` と `pi` の両方を使えます。 |
| 自然対数の底 | `e^2` | 無次元の数値として計算します。 |

> 三角関数の出力は無次元です。`sin(1m)` のように長さ・質量などを引数にした式、`sqrt(2m)` のように次元の指数を半分にできない式は、意図しない換算を防ぐためエラーになります。

## 特殊単位の扱い

上級モードでは `Gal`、`G`、`g0`、`kine`、`kt`、`mph` などに情報ボタンを表示します。タップすると、単位名、SI換算値、主な利用分野を英語または日本語で確認できます。
