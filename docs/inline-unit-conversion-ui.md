# 一画面で完結する単位入力と結果変換

## 課題

スマートフォンでの利用時に、電卓画面が縦に伸びてスクロールが必要になっていました。表示単位の切り替えが結果カードより下に離れていたため、結果を見ながら単位を変える操作が遠く、単位の入力も「使える表記かどうか」が押すまで分かりませんでした。

## 画面構成

電卓画面はスクロールしない固定レイアウトへ変更しました。上から順に、見出し、入力カード、結果領域、ツール行、キーパッドを配置し、余った高さは結果領域が受け取ります。iPhone SE相当（667pt）でもキーパッドまで収まり、狭い端末では結果領域の内側だけがスクロールします。

| 位置 | 内容 | 意図 |
| --- | --- | --- |
| 入力カード | 式の入力欄、`=` ボタン、式のハイライト、単位の候補バー | 入力と単位の確定を同じ場所で完結させる |
| 結果領域 | 結果値、単位切り替えバー、SI標準値、エラー、履歴 | 結果のすぐ下で表示単位を変えられる |
| ツール行 | サンプル、単位、速度、数学 | 補助機能はモーダルへ退避して高さを使わない |
| キーパッド | 数字・演算子・`=` | 画面幅に関係なく必ず4列で並ぶ |

キーパッドは25%幅のセルへ収めたため、320pt幅の端末でも4列を維持します。

## 式の表記を見分ける

入力欄の直下に式を分解して表示します。数値、単位、定数・関数、演算子を色で描き分け、計算できない表記だけを赤い下線と警告アイコンで示します。赤い部分をタップすると、その単位の修正候補が候補バーへ切り替わります。

| 区分 | 表示 | 例 |
| --- | --- | --- |
| 数値 | 標準色 | `120` |
| 単位 | 強調色・太字 | `km`、`m/s`、`hour` |
| 定数・関数 | 注意色 | `W`、`a1`、`sin` |
| 計算できない表記 | 赤の下線＋警告アイコン | `kmh`、`hoge` |

定数を定義する `W = 3cm` の左辺は、まだ保存されていなくても未登録として警告しません。

## 単位の候補バー

入力欄の下の候補バーは、式の状態に合わせて役割を変えます。候補は記号と読みを2段で表示し、タップした時点で式へ確定します。

| 状態 | 役割 | 動作 |
| --- | --- | --- |
| 計算できない単位がある | 要修正 | 該当箇所を候補の記号へ置き換える |
| 数値の直後に書きかけの単位がある | 確定 | 書きかけを候補の記号へ置き換える |
| 数値で終わっている | 単位付け | 数値の直後へ単位を追加する |
| それ以外 | 単位挿入 | 末尾へ単位を追加する（直近に使った単位を優先） |

候補は記号の一致だけでなく、`hour`・`inch`・`キロメートル` のような読み、`kmh`・`hoir` のような打ち間違いからも導きます。虫めがねボタンからは、カテゴリ別の一覧と検索を持つ単位シートを開きます。単位シートは地域の優先単位を先頭に置いたうえで、そのカテゴリの全単位を表示します。

## 結果のとなりで単位を変える

結果値の直下に、その結果と同じ次元の単位だけを並べた切り替えバーを置きました。先頭の `SI` はSI標準値へ戻す選択肢で、`他` から単位シートを開きます。以前は結果カードの下にあった表示単位の選択欄を廃止し、結果を見ながら1タップで読み替えられるようにしました。

表示単位が結果の次元に合わない場合は、行き止まりにせずSI標準値へ戻して案内します。履歴も同じ表示単位で保存します。

## 時間の単位

`min` だけが略さない表記だったため、時間単位の別表記を追加しました。式の中でも次の表記を計算できます。

| 記号 | 読み | 計算できる別表記 |
| --- | --- | --- |
| `s` | 秒 | `sec`、`secs`、`second`、`seconds` |
| `ms` | ミリ秒 | `msec`、`msecs` |
| `min` | 分 | `mins`、`minute`、`minutes` |
| `h` | 時間 | `hr`、`hrs`、`hour`、`hours` |
| `d` | 日 | `day`、`days` |

`120km ÷ 2hour`、`90sec`、`500msec` のような式をそのまま計算できます。`km/hour` や `m/sec` のような複合単位も同じ規則で解釈します。長さ・質量・速度などの主要な単位にも読みと別表記を登録したため、単位シートでは記号の下に読みが表示され、検索は英語名・日本語名の両方に反応します。
