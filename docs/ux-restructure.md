# 初心者優先の情報設計

## 設計方針

この更新では、日常的な単位換算を行う利用者が、専門的な機能の多さに圧倒されないことを最優先にしました。標準の**シンプルモード**では基本の単位・四則演算・日常的なサンプルだけを前面に置きます。専門的な計算が必要な場合だけ、設定で**上級モード**へ切り替えます。

| 利用場面 | 最短の操作 | 支援する要素 |
| --- | --- | --- |
| 初めての換算 | サンプルを選ぶ → 式を確認 → 計算 | 基本カテゴリ、互換単位だけの表示 |
| 繰り返す計算 | 結果からテンプレートへ保存 → ライブラリから再利用 | 式・表示単位を自動で引き継ぐ導線 |
| 専門計算 | 設定で上級モード → 数学キーまたは上級サンプル | 角度、三角関数、対数、次元エラーの説明 |
| 複数手順の計算 | ライブラリ → 計算ノート → 各手順を実行 | 手順ごとの式と表示単位を一か所で管理 |

## ライブラリの役割

従来の「定数」画面を**ライブラリ**へ再構成しました。テンプレート、計算ノート、自作関数、定数を同じ場所で管理します。最初に表示するのはテンプレートであり、保存した式をワンタップで電卓へ戻せます。高度な機能を利用しない場合は、定数・テンプレートだけを使えばよく、関数やノートの作成は必須ではありません。

## 数学機能の安全策

三角・逆三角・対数・べき乗・平方根は、無次元または角度として解釈できる値だけを受け付けます。`atan2(y, x)` は2つの引数が同じ次元でなければ実行しません。単位付きのべき乗・平方根は、次元の整合性を検査してから評価します。これにより、見た目だけ正しいが物理的には不整合な計算を防ぎます。
