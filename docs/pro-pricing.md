# UnitCalc Pro の価格（買い切り1本）

価格の実体は `docs/pro-pricing.csv`。このファイルはその**根拠**と、反映のしかたを書いたもの。

## 先に重要な訂正: Play Console の価格CSVインポートは廃止されている

**2025-05-19 に Play Console のアプリ内アイテムの CSV インポート/エクスポートが廃止された。**
さらに**2025-10-27 に価格テンプレートも廃止**され、既存のテンプレートは自動で解除されて
各商品に価格が展開された。つまり:

- **`docs/pro-pricing.csv` を Play Console に読み込ませることはできない。**
- **一括で入れる手段は Play Developer API だけ**（新APIの `monetization.onetimeproducts.patch`）。
- 手でやるなら Play Console の商品ページで国ごとに入力する（31カ国ぶん）。

このCSVは**このリポジトリ側の唯一の情報源**として持ち、APIへ流し込む入力に使う。
git で差分が読めるので、「いつ・なぜこの値にしたか」が追える。

## 決めた価格

**基準は US $4.99。** 根拠は競合の実勢で、**ターゲットが実際に買っているアプリが $3.99〜$4.99 に収束している**:

| アプリ | 価格 | 誰が買うか |
|---|---|---|
| Electrodoc Pro | $4.99 | 電気・電子の実務者 |
| Mobile Electrician Pro | $4.99 | 電気工事 |
| Electrical Calculation PRO | $3.99 | 電気設計 |
| HiPER Calc Pro | $4.99 | 関数電卓 |
| RealCalc Plus | $3.99 | 関数電卓 |

Android の買い切り実用アプリの上限もこのあたり（Tasker $3.49 / Torque Pro $4.95 / DAVx⁵ €5.99）。
**実績のあるアプリでもこの帯にいる**ので、レビュー0件で上に出るのは分が悪い。

**$2.99 にしない理由**: そこは「広告を消すだけ」の価格帯で、次元チェック・有効数字・194件のノートが
その枠で読まれてしまう。Proの訴求は**広告除去ではなく機能**（CSV書き出し・マイ単位セット・PDF共有）で立てる。

**逆に強い材料**: 競合の解答アプリは軒並みサブスクへ移った（Photomath $9.99/月・Mathway $9.99/月・
Symbolab・Wolfram|Alpha Pro）。**$4.99 の買い切りは「1か月ぶんより安くて永久」**で、掲載文にそのまま書ける。
同じ分野の CalcNote が2025年11月にサブスクへ移行した（旧Pro版は¥9,900という実質的な締め出し価格）のは、
こちらの「サブスクなし」が**今まさに空いている場所**であることを示している。

### 国ごとの考え方

**高所得の市場は自動変換で問題ない**（為替が購買力とほぼ一致するため）。CSVで上書きするのは次の2種類だけ:

1. **心理的な価格を置きたい市場**（US / JP / GB / ユーロ圏）
2. **購買力と為替が乖離する市場**（中南米・インド・インドネシア・トルコ）

CSVに無い国は `autoConvertMissingPrices=true` で Play に変換させる。Google が下限・上限・
端数の慣習（`¥500`・`R$24,90`）・地域ごとの税を全部やってくれるので、**自前で下限表を持たない。**

### 税込み・税抜きを取り違えないこと

**基準価格は税抜き、各国に保存される価格は税込み**（Play API のドキュメントがそう定義している）。
日本の消費税もEUのVATも**表示価格に含まれる**ので、手取りは `表示価格 ÷ (1+税率)`。

ここを外すと静かに目減りする:

| | 為替そのまま | 採用値 | 手取り |
|---|---|---|---|
| 日本 | ¥769 | **¥800** | ¥727 ≈ $4.72 |
| ユーロ圏 | €4.29 | **€4.99** | €4.19 ≈ $4.87 |

**€4.29 にすると手取りが US より16%低くなる。** €4.99 は「高くしている」のではなく**等価に揃えている**。

### 日本を ¥490 にしないこと

`¥120 / ¥250 / ¥370 / ¥490 / ¥610` の階段は**2022年12月に作り直される前の Apple のティア表**で、
**Google Play には元々存在しない**。しかも当時は1ドル110円前後だった。**現在の154円では ¥490 は $3.18 で、
最もARPUの高い市場で36%引きになる。** 現行の自然な刻みは `¥300 / ¥400 / ¥500 / ¥600 / ¥800 / ¥980 / ¥1,200`。

**日本にPPPを当てないこと。** 円安で日本の物価水準比は1.0を大きく下回っているため、機械的なPPP計算は
¥500前後を出してくる。しかし市場の実績は逆で、日本は Google Play の収益で米国を抜いている。
**購買力ではなく市場実績で決める。**

### ユーロ圏は全加盟国を明示する

一部の国だけ書くと残りが自動変換され、**同じユーロ圏で €4.99 と €5.10 が混在**して見える。
20カ国すべてを €4.99 で明示してある（AT BE CY DE EE ES FI FR GR HR IE IT LT LU LV MT NL PT SI SK）。

> スペインだけ €3.99 にする案もある（物価水準がドイツより低い）。ただし**ユーロ圏内の価格差は
> 大陸をまたぐ差より利用者に見えやすい**ので、まずは全域 €4.99 で出す。

### 中南米の導出

為替レートを自前で作らず、**実在する $9.99 商品の Play 自動変換後の価格**を手掛かりにした
（この値には既に現地の税が乗っている）。そこから $4.99 相当へ按分し、購買力の係数を掛けている。

| 国 | $4.99 の自動変換 | 採用値 | 対US |
|---|---|---|---|
| ブラジル | R$30.96 | **R$14.90** | 約0.58× |
| メキシコ | MX$119 | **MX$59** | 約0.70× |
| コロンビア | COP 21,728 | **COP 7,900** | 約0.51× |
| チリ | CLP 6,044 | **CLP 2,900** | 約0.48×（BR/MXと同じ係数で導出） |
| ペルー | PEN 18.98 | **PEN 8.90** | 約0.48×（同上） |

端数は現地の慣習に合わせた（**ブラジルは `,90`** で `.99` ではない、メキシコは末尾9、
コロンビア・チリはゼロ小数通貨なので整数）。

## 運用

- **トルコは四半期ごとに見直す。** 為替の変動が大きく、固定した現地価格がすぐ陳腐化する。
  同様に注意が要るのは ARS・NGN・EGP・PKR。
- **アルゼンチンは行を作っていない。** 実在の価格表サンプル（90カ国規模）にARが1つも出てこないため、
  **個別に価格を設定できず「その他の地域」のUSD枠に落ちる可能性がある**。Play Console で確認してから足す。
- **ロシアは行を作らない**（Playの有料取引が停止中）。
- **2026年のPlay手数料改定**: 年間$100万までは実効15%（サービス10%＋課金5%）で従来と実質同じなので、
  この価格を見直す理由にはならない。日本・韓国への適用は2026-12-31。
- **launch後は Play Console の価格テストで詰める。** まず試す価値があるのは **日本 ¥800 対 ¥980** と
  **US $4.99 対 $6.99** の2つ。日本の受験者は教科書1冊に¥3,000〜4,000払う層なので ¥980 は十分あり得る。

## 調査の限界（鵜呑みにしないこと）

- **競合の価格は検索結果からの抽出で、実際のストア画面を開いて確認していない**（この環境から
  `play.google.com` に到達できない）。**掲載前に Electrodoc Pro・Mobile Electrician Pro・
  HiPER Calc Pro・RealCalc Plus の4本は自分で見て確かめること。** ここが $3.99〜$4.99 でなければ基準価格が動く。
- **$0.99/$1.99/$2.99/$4.99/$9.99 の転換率を比べた公開データは見つからなかった。** 価格帯の切れ目に
  ついての記述は判断であって実証ではない。
- **購買力調整で収益が何%増えるかの数字（+15%〜+350%）はベンダーの宣伝**で、方法論が公開されていない。
  方向性は広く支持されているが、倍率は信用しない。
- **ドイツの「支払い意欲が高い」は元の想定より根拠が弱い。** 広告回避（ネット利用者の約49%が
  広告ブロッカー、欧州最高）は堅いが、支払い意欲は「月5ユーロまでなら34%」という調査で、
  **高いのではなく€5前後に集中している**。結論（€4.99）は変わらないが、理由は変わる。
