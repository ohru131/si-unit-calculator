# 類似アプリ調査：導入機能とロードマップ

## 結論

PCalcは編集可能な変換・関数・定数、紙テープ履歴、RPN、ショートカットを備えた「高機能計算環境」である。[1] CalConvertは600超の単位、頻用項目の保存、履歴共有、ウィジェット、多言語化で「日常的な変換の速さ」を重視している。[2] Unit Converter Ultimateは設定を増やしすぎず、欲しい変換への到達速度を重視する。[3]

単位付き電卓は、SI正規化と次元検証という強みを維持しながら、**発見・再利用・外部への受け渡し**を改善するのが最も効果的である。今回、競合の共通価値である単位検索と結果コピーを実装した。

## 導入状況と優先順位

| 優先度 | 機能 | 競合の根拠 | 現在の対応 | 判断 |
|---|---|---|---|---|
| P0 | 単位・カテゴリの検索 | 多カテゴリを素早く扱うCalConvertと、単純な到達経路を重視するUnit Converter Ultimate。[2] [3] | **実装済み**。地域プリセットを尊重して記号／カテゴリで候補を絞り、タップで式へ挿入する。 | 日常操作の摩擦を即時に減らす。 |
| P0 | 結果のコピー | CalConvertは履歴のコピー・再利用・共有を提供する。[2] | **実装済み**。式、表示結果、SI基準値をワンタップでコピーする。 | チャット、メール、レポート、スプレッドシートへ渡しやすい。 |
| P1 | 計算ノート／ピン留めテンプレート | PCalcの紙テープ履歴と編集可能な関数・定数。[1] | 次の候補。式・説明・タグ・入力欄を持つテンプレートを保存する。 | 研究・授業・現場での反復作業に強い差別化となる。 |
| P1 | ウィジェットとショートカット | CalConvertのホーム画面ウィジェット、PCalcのSiri Shortcuts。[1] [2] | 次の候補。最後の計算、検索、定番テンプレートへのショートカットを提供する。 | アプリを開くまでの時間を削減する。 |
| P1 | カスタム単位／派生量エディター | PCalcの編集可能な変換・関数・定数。[1] | 次の候補。換算係数・基準単位・表示名を検証付きで登録する。 | 業界固有の単位を扱える。数式と次元検証が必須。 |
| P2 | 工学表記・有効数字・不確かさ | PCalcの工学／科学表記。[1] | 次の候補。表示設定と計測値の桁ルールを追加する。 | 研究・技術者の信頼を高めるが、初回利用の複雑さを増やす。 |
| P3 | ライブ通貨・世界時計 | CalConvertの通貨・世界時計。[2] | **保留**。通貨レートにはネットワーク依存・更新責任があり、Unit Converter Ultimateもその依存を明示している。[3] | オフラインかつ次元計算中心という製品軸を保つ。 |

## 推奨する次の実装順

まず、計算ノート／ピン留めテンプレートを追加し、既存の定数・履歴・サンプルをひとつの「再利用可能な計算資産」として統合する。次に、ホーム画面ウィジェットとOSショートカットで、検索・最後の計算・定番テンプレートを起動できるようにする。最後に、カスタム単位エディターと工学表記をPro機能として検討する。
