# グローバル製品化：調査メモ

## ストアとローカリゼーション

Appleは、App Storeが175地域・50言語で利用できるとしており、アプリの国際化では、ユーザーが表示するテキスト・画像をコードから分離し、複数言語・地域の値、単位、価格を適切に表現することを推奨している。[1] iOSとiPadOSでは、端末言語と別にアプリごとの優先言語を選べるため、端末ロケールの自動判定に加えて、アプリ内で明示的に言語を選べる設計が妥当である。[1]

Google Playでは、ストア掲載文、アプリ内文字列、アプリ内プロダクトを翻訳でき、ローカライズ済みテキストとグラフィックアセットを追加できる。ユーザーの言語設定に一致する翻訳を表示する仕組みであり、国・地域別に表示を変えたい場合はカスタムストア掲載を使える。[2]

## このアプリへ反映する方針

| 領域 | 初回対応 | 理由 |
|---|---|---|
| 言語 | 英語・日本語、端末言語からの初期判定、アプリ内切替 | 初期市場を広くカバーし、二言語利用者にも選択肢を提供する。 |
| 単位系 | Metric、US customary、Imperialのプリセット | 同じ次元を維持したまま、地域で慣用的な入力・表示単位を初期提案できる。 |
| アクセシビリティ | 読み上げラベル、操作対象の説明、文字拡大に耐える縦積み | 数式や単位の意味を、視覚以外の経路でも理解できるようにする。 |
| ストア公開 | 言語別説明・画像・Pro商品情報・プライバシー | アプリ内だけでなく、発見から購入までの体験を各地域に合わせる。 |
